เปลี่ยนความฝันให้เป็นกุญแจ แล้วเปิดกล่องสมบัติ

เลือกความฝันที่อยากทำให้สำเร็จ แล้วขั้นตอนเล็กๆ ที่พาไปถึงจะกลายเป็นฟันกุญแจ ตอบคำถามทีละข้อ แล้วกล่องก็จะเปิดออกโดยไม่รู้ตัว

ดาวน์โหลดบน App Store

ทะเลแห่งความฝัน

ความฝันกว่า 590 ข้อทั้งการท่องเที่ยว ประสบการณ์ ความสำเร็จ สุขภาพ การเรียนรู้ และความสัมพันธ์ ลอยอยู่ในกล่อง นำข้อที่ชอบกลับบ้าน หรือสร้างความฝันของคุณเอง

หล่อกุญแจ

ทุกความฝันถูกแบ่งเป็นขั้นตอนที่เป็นฟันกุญแจ ขั้นที่ต้องทำตอนนี้อยู่บนสุด และมีคำถามช่วยให้ทำขั้นนั้นจนเสร็จ

บันทึกและรูปภาพ

คำตอบและรูปภาพของคุณสะสมอยู่ในบันทึก ย้อนดูเส้นทางทั้งหมดได้ในไทม์ไลน์ความคืบหน้า

คลังสมบัติและแผนที่

ความฝันที่สำเร็จจะเก็บไว้ในคลังสมบัติ ส่วนความฝันที่มีสถานที่จะอยู่บนแผนที่ ความฝันที่พักไว้เริ่มต่อได้ทุกเมื่อ

ไม่ต้องมีบัญชี ไม่มีโฆษณา ความฝันและบันทึกของคุณอยู่ในเครื่องเท่านั้น
