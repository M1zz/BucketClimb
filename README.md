# BucketClimb - 버킷리스트 등산 앱

## 🎯 개요
BucketClimb는 버킷리스트를 단순한 목록이 아닌, 실제로 실행 가능한 등반 과정으로 변환하는 iOS 앱입니다. 등산 메타포를 활용하여 꿈을 향한 여정을 시각화하고, 장애물을 체계적으로 제거해나가는 과정을 게임처럼 즐길 수 있습니다.

## ✨ 핵심 기능

### 📥 페이즈 1: 버킷 채우기 (Dreaming)
- 6가지 카테고리별 버킷리스트 탐색 (여행, 경험, 성취, 관계, 건강, 배움)
- 직관적인 버킷 시각화 (채워지는 정도를 퍼센트로 표시)
- 간편한 꿈 추가 인터페이스

### 📤 페이즈 2: 버킷 비우기 (Doing)

#### 장애물 메타인지 🚧
각 버킷리스트를 막고 있는 구체적인 장애물 파악:
- 💰 **비용**: 필요한 금액과 현재 저축액
- ⏰ **시간**: 필요한 시간과 현재 가용 시간
- 💪 **체력/스킬**: 필요한 신체적/기술적 능력
- 📚 **지식**: 학습이나 조사가 필요한 부분
- 📅 **타이밍**: 시즌이나 기회의 창

#### 베이스캠프 시스템 ⛺️
- 장애물을 달성 가능한 중간 목표로 변환
- 단계별 체크리스트로 진행상황 관리
- 완료 시 자동 날짜 기록

#### 일일 진행 추적 📈
- "오늘 에베레스트에 19cm 가까워졌어요" 식의 즉각적 피드백
- 작은 행동들의 누적 효과 시각화
- 등반 진행률 실시간 업데이트

#### 산 시각화 🏔️
- 각 버킷리스트를 산 높이로 표현
- 등반자 아이콘으로 현재 위치 표시
- 진행률에 따른 색상 변화 효과

### 🏆 아카이브
- 완료된 버킷리스트 트로피 갤러리
- 통계 및 성취 기록 대시보드
- 완료 날짜별 정렬 및 회고

## 🛠 기술 스택
- **언어**: Swift 5.0
- **UI 프레임워크**: SwiftUI
- **아키텍처**: MVVM (Model-View-ViewModel)
- **데이터 저장**: UserDefaults
- **최소 요구사항**: iOS 17.0+
- **개발 환경**: Xcode 15.0+

## 🚀 설치 및 실행

### 요구사항
- macOS (최신 버전 권장)
- Xcode 15.0 이상
- iOS 시뮬레이터 또는 iOS 17.0+ 실제 기기

### 실행 방법

1. **압축 해제**
   ```bash
   unzip BucketClimb.zip
   cd BucketClimb
   ```

2. **Xcode에서 프로젝트 열기**
   ```bash
   open BucketClimb.xcodeproj
   ```
   
   또는 Xcode를 실행하고 File → Open에서 `BucketClimb.xcodeproj` 선택

3. **시뮬레이터 선택**
   - 상단 툴바에서 원하는 iOS 시뮬레이터 선택 (예: iPhone 15 Pro)

4. **빌드 및 실행**
   - `⌘ + R` 키를 누르거나
   - 상단의 ▶️ (Play) 버튼 클릭

## 💡 사용 예시

### 예시 1: 아이슬란드 오로라 보기

1. **버킷 채우기 탭**에서 "여행" 카테고리 선택
2. "아이슬란드에서 오로라 보기" 추가
3. 상세 화면에서 **"등반 시작하기"** 버튼 클릭

앱이 자동으로 장애물 분석:
- 💰 여행 경비: 30만원 / 250만원
- ⏰ 휴가 일수: 3일 / 7일  
- 📅 적절한 시즌: 미예약 / 예약 필요
- 📚 여행 계획: 미완료 / 완료 필요

베이스캠프가 자동 생성:
1. ✅ 레이캬비크 vs 북부 리서치
2. ⬜ 월 30만원 저축 시작
3. ⬜ 휴가 일정 협의
4. ⬜ 항공권 예매
5. ⬜ 투어 예약

4. 일일 진행 기록:
   - "5만원 저축" → "레이캬비크까지 0.2km 가까워짐!"
   - "휴가 승인 받음" → "타이밍 장애물 클리어! 🎉"

5. 모든 베이스캠프 완료 시 **"등반 완료!"** 버튼으로 아카이브에 저장

## 📊 샘플 데이터

앱을 처음 실행하면 3개의 샘플 버킷리스트가 자동 생성됩니다:

1. **아이슬란드에서 오로라 보기** (2.5km 산)
   - 카테고리: 여행
   - 예상 기간: 8개월
   
2. **에베레스트 베이스캠프 트레킹** (5.3km 산)
   - 카테고리: 성취
   - 예상 기간: 2년
   
3. **프랑스어 유창하게 구사하기** (4.0km 산)
   - 카테고리: 배움
   - 예상 기간: 1.5년

각 샘플에는 실제적인 장애물과 베이스캠프가 미리 설정되어 있어 앱의 모든 기능을 즉시 체험할 수 있습니다.

## 🎨 주요 UI 컴포넌트

### 버킷 시각화
- 채워지는 애니메이션과 퍼센트 표시
- 그라디언트 컬러로 시각적 만족감 제공

### 산 그래픽
- 삼각형 모양의 산 실루엣
- 등반 진행에 따라 색상이 채워지는 효과
- 등반자 아이콘이 실시간으로 위치 이동

### 장애물 진행 바
- 각 장애물의 진행률을 시각적으로 표현
- 완료 시 녹색 체크마크 표시

### 베이스캠프 체크리스트
- 탭으로 간편하게 완료 토글
- 완료된 항목은 취소선과 녹색 배경
